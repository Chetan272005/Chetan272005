## 🚀 Featured Project

### 🛒 Online Shopping Cart System

An interactive **Online Shopping Cart System** built using HTML, CSS and JavaScript.

### ✨ Features

- 🛍️ Product catalog
- ➕ Add products
- 🗑️ Delete products
- 🛒 Add products to cart
- 🔢 Quantity management
- 💰 Automatic price calculation
- 📦 Order processing
- 🔄 FIFO Queue for order processing
- 📚 LIFO Stack for order history
- 🔔 User notifications
- 📱 Responsive interface

### 🧠 Data Structures Used

```text
Array
  ↓
Product Catalog

Linked List
  ↓
Shopping Cart

Queue (FIFO)
  ↓
Order Processing

Stack (LIFO)
  ↓
Order History
```
